# Aplikasi Kasir Restoran

Program kasir restoran sederhana menggunakan bahasa Python.

## Fitur
- Menampilkan daftar menu makanan
- Memilih menu makanan
- Memasukkan jumlah pesanan
- Menghitung total belanja
- Memberikan diskon 20% jika total belanja lebih dari Rp200.000
- Menampilkan struk pembelian

## Cara Menjalankan
1. Pastikan Python sudah terinstal.
2. Buka terminal.
3. Jalankan perintah:

   python kasir.py
